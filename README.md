# Harsh Jajoria Portfolio

A dependency-free responsive portfolio site for Harsh Jajoria.

## Edit content

- Update skills and projects in `script.js`.
- Replace placeholder contact links and email in `index.html`.
- Replace education, experience, certifications, and resume placeholders in `index.html`.
- Update colors, typography, and responsive rules in `styles.css`.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server. No build step is required.
